Codex Workspace Privacy Policy

Last updated: 2026-10-03

Who uses this application

Codex Workspace is a personal OAuth client. It is used by one person only - its owner - on the owner's own computer, to connect a locally running AI assistant (Codex) to the owner's own Google account (zhoukai.wh@gmail.com).

What data is accessed

With the owner's permission, the application accesses the owner's own Gmail messages and Google Drive files through the official Gmail API and Google Drive API. It can read, organize, create drafts and send email, and it can read, upload, update and organize Drive files, only when instructed by the owner.

How the data is used

The data is used solely to carry out the owner's instructions inside the local AI assistant. It is never used for advertising, profiling or any other purpose.

How the data is stored

OAuth tokens are stored locally on the owner's computer. Message content, files and attachments are processed in memory during a request and are not kept on any server. No data is stored in the cloud by this application.

Data sharing

No data is sold, shared or transferred to any third party. Data is transmitted only between the owner's computer and Google's APIs.

Retention and deletion

The application keeps no copy of the owner's data beyond the local OAuth tokens. The owner can revoke access at any time at myaccount.google.com/permissions and can delete the locally stored tokens at any time.

Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
